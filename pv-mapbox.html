    Karten-Stil

    Standard ist die MapTiler-Vektorkarte (Streets v2, mit 3D-Gebäuden) über einen eingebauten Test-Token von A&B Solarenergy. Du kannst hier optional einen eigenen MapTiler-Token eintragen (z.B. für die Produktion mit Domain-Restriction) oder leer speichern, um auf das einfachere OSM-Raster zu wechseln.

    1. Eigenen Token holen (optional, kostenlos): auf cloud.maptiler.com registrieren.
    2. Nach Login → Account → API keys → Default-Key kopieren.
    3. Hier einfügen, Speichern → Karte lädt neu mit deinem Token.
